# 또봄 (NextMeet) — 아이디어톤 프로토타입

> 같은 동네 다섯 명이, 정해진 날 또 봐요.

복지관·문화센터 강좌가 끝난 뒤, 수강생들이 동네 소모임으로 계속 만나도록 돕는 시니어 커뮤니티 서비스의 **모바일 웹 데모**입니다.
계모임의 정기성과 소속감은 가져오되, 금전 거래는 전혀 다루지 않습니다.

## 데모 흐름

1. **초대코드 입력**: 데모 코드는 `1013`
2. **내 소개**: 이름과 동네
3. **관심사·시간 선택**
4. **둘러보기**: 복지관·동네 가게·이웃 강사·주민이 여는 강좌와 모임 목록입니다.
   - 고른 관심사·동네·시간이 겹치는 것을 먼저 보여 줍니다(단순 정렬).
   - 상단에서 `전체 / 강좌 / 모임 / 동네 가게`로 나눠 볼 수 있습니다.
5. **강좌 신청 → 이어지는 모임**: 강좌 상세에 "강좌가 끝나면 같은 반 분들과 ○○ 모임으로 계속 만날 수 있어요" 연결이 있습니다.
   - 재료비는 앱에서 결제하지 않고 현장에서 직접 냅니다.
6. **내 모임**: 여러 모임에 들어갈 수 있고, 상단에서 모임을 바꿔 봅니다. 신청한 강좌도 여기에 보입니다.
7. **안부**: 보내기(잘 지내요 / 이야기하고 싶어요 / 며칠 쉬어요)와 응답(반가워요 / 전화할게요 / 푹 쉬세요)
8. **만남**
   - 다가오는 만남 목록에서 갈게요 / 이번엔 못 가요를 고릅니다.
   - **모임원 누구나 다음 만남을 제안**할 수 있습니다. 날짜·시간·공개 장소를 고르기만 하면 됩니다.
9. **강좌·모임 제안하기**: 동네 주민(모임), 이웃 강사(강좌), 동네 가게·공방(강좌)으로 제안합니다.
   - 진행자가 확인해야 둘러보기에 올라갑니다.
   - 제안 화면의 "예시로 채워 보기"로 빠르게 시연할 수 있습니다.
10. **일자리**: 둘러보기 상단의 `일자리` 탭에서 복지관·주민센터 어르신 일자리와 동네 가게 일을 소개합니다(모두 가상 예시).
    - 또봄은 지원·채용을 처리하지 않습니다. ‘관심 있어요’를 누르면 진행자 화면에 표시되고, 진행자가 전화로 안내하는 흐름입니다.
    - 선입금·물건 구매·투자 권유형 "일자리"는 신고하도록 안내합니다.
11. **도움**: 불편한 일 알리기, 진행자 연락, 모임 나가기

화면 구성은 동네 기반 모임 앱의 익숙한 패턴(위치 헤더, 아이콘 카테고리 줄, 구분선 목록, 떠 있는 만들기 버튼, 하단 고정 가입 버튼, 날짜 블록 일정)을 참고했고, 색과 글자 크기는 또봄 기준을 따릅니다.

배포 주소: https://nextmeet-jade.vercel.app

### 진행자 화면 (`#/host`)

- **제안 검토**: 둘러보기에 올리기 / 이번엔 어려워요
- **신고 확인**
- **일자리 관심 표시 목록**
- **모임별 만남 목록과 참석 집계**, 만남 추가
- **복지관 강좌·모임 직접 올리기**

같은 브라우저의 두 탭에 회원 화면과 진행자 화면을 띄우면, 한쪽에서 바꾼 내용이 다른 쪽에 바로 반영됩니다.
예: 회원이 제안 → 진행자가 승인 → 회원 둘러보기에 "새로 올라옴" 표시

### 누가 무엇을 만드나

| 무엇 | 누가 | 어떻게 |
|---|---|---|
| 강좌 | 복지관 | 진행자 화면에서 바로 올림 |
| 강좌 | 동네 가게·이웃 강사 | 회원 화면에서 제안 → 진행자 확인 후 게시 |
| 모임 | 복지관 | 진행자 화면에서 바로 올림 |
| 모임 | 주민 | 회원 화면에서 제안 → 진행자 확인 후 게시. 제안한 사람이 첫 모임원이 됨 |
| 만남 | 진행자 | 진행자 화면에서 추가 (첫 몇 회) |
| 만남 | 모임원 누구나 | 만남 탭 → 다음 만남 제안하기 |

## 실제 동작 vs 가상

| 구분 | 내용 |
|---|---|
| **실제로 동작** | 화면 이동, 입력 저장(브라우저 localStorage), 안부 전송·응답, 참석 응답, 신고 접수 → 진행자 화면 표시, 진행자의 만남 등록 → 회원 화면 반영 |
| **가상 데이터** | 모든 모임, 모임원, 기관명, 다른 사람의 안부·참석 응답. 내 안부에 오는 응답은 2.6초 뒤 나타나는 **스크립트**이며, 화면에 `예시 응답`으로 표시합니다. |
| **구현하지 않음** | 서버, 계정, 본인 확인, 문자·푸시 알림, 실제 전화 연결, 자동 매칭, 결제, 가게·강사 검증, 외부 연동 |

## 설계 원칙

- 출석 점수, 연속 기록, 순위, 미응답자 표시를 두지 않습니다.
- 답이 없는 것을 이상 신호로 판단하지 않고, 가족에게 자동으로 알리지 않습니다.
- 진행자에게도 개인별 안부 기록을 보여 주지 않습니다.
- 낯선 사람 프로필 검색과 1:1 메시지를 두지 않습니다. 전화번호는 본인이 공개에 동의한 경우에만 연결합니다.
- 첫 만남은 공개된 장소에서, 진행자가 함께 나가는 것을 전제로 합니다. 회원이 만남을 제안할 때도 공개 장소 목록에서만 고릅니다.
- 모임원끼리는 돈을 주고받지 않습니다. 가게·강사 강좌의 재료비는 금액을 미리 표시하고 현장에서 직접 냅니다. 가게는 물건 구매를 권하지 않는 조건으로 연계합니다.

## 실행

```bash
npm install
npm run dev
```

빌드 결과물(`dist/`)은 정적 호스팅(Vercel, GitHub Pages 등)에 올리면 됩니다.
