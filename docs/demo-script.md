# 또봄 90초 데모 시나리오

> 핵심 메시지: **"시놀·당근은 모임을 찾게 해 주고, 복지관은 강좌를 열어 줍니다. 또봄은 강좌가 끝난 뒤 그 관계가 끊기지 않게 합니다."**

데모 주소: https://nextmeet-jade.vercel.app (진행자 화면은 주소 끝에 `#/host`)

## 시연 전 준비 (발표 10분 전)

1. 휴대폰 또는 브라우저 모바일 보기(375px)로 데모 주소를 엽니다.
2. 도움 탭 → **데모 처음부터 다시 하기**로 초기화합니다.
3. 가입을 미리 해 둡니다. 데모 시간에 가입을 보여 주지 않기 위해서입니다.
   - 초대코드 `1013` → 이름 **정희** → **망원동** → 관심사 **휴대폰 사진** → **평일 오전**
   - **강좌·모임 보러 가기**까지 눌러 둘러보기 화면에서 멈춥니다.
4. 백업: 네트워크가 끊길 때를 대비해 아래 장면별 화면 녹화(30~40초)를 준비합니다.

## 말하지 않을 것 (정직하게)

- 앱이 외로움이나 우울을 줄인다고 말하지 않습니다. 검증하지 않았습니다.
- 다른 모임원의 응답은 **예시**입니다. 실시간처럼 말하지 않습니다.
- 알림, 매칭, 결제, 본인 확인은 구현하지 않았습니다.

## 시간이 남거나 질문이 나오면 (선택 시연)

- **"가게가 영업하면요?"** → 진행자 화면(`#/host`)을 새 탭에 띄웁니다. 회원 화면에서 **＋ 제안하기 → 동네 가게·공방 → 예시로 채워 보기 → 진행자에게 제안 보내기**를 누르고, 진행자 화면에서 **둘러보기에 올리기**를 보여 줍니다. 가게 강좌 상세의 "물건 구매를 권하지 않기로 약속했어요" 문구와 **도움 → 불편한 일 알리기**도 짚습니다.
- **"AI 안부전화(클로바 케어콜)가 이미 있지 않나요?"** → "케어콜은 기관이 어르신을 확인하는 돌봄 서비스이고, 또봄은 모임원끼리 서로 안부를 묻는 관계 서비스입니다. 미응답을 이상 신호로 보지 않는 것도 의도된 차이입니다."
- **"시놀 같은 시니어 모임 앱과 뭐가 다른가요?"** → "새 사람을 찾는 앱이 아니라, 이미 한 번 만난 강좌 동기를 다시 만나게 하는 구조입니다. 그래서 복지관이 모집 채널이자 구매자가 됩니다."
- **"일자리도 하나요?"** → "직접 하지 않습니다. 도움 탭에서 공공 '노인일자리여기'와 진행자 안내로 연결만 합니다."
